# Marcos Andaya | Real Estate VA Portfolio

Static portfolio site: plain HTML, CSS and JavaScript. No build step.

## Put it online with GitHub Pages
1. Create a new public repository (for example `marcos-andaya-portfolio`).
2. Upload everything in this folder, keeping the `assets` folder structure.
3. In the repository go to **Settings > Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then Save.
4. Your site appears at `https://<your-username>.github.io/<repository-name>/` in a minute or two.

## Edit it
- Text and work samples: `index.html`
- Colors and fonts: variables at the top of `style.css`
- Add a work sample: copy one `<figure class="card">` block and point it to a new file in `assets/img`
